1. Название и описание задачи
Мини-графический редактор — консольное приложение на Python, реализованное с использованием принципов ООП. Его функционал включает:
создание геометрических объектов (кругов и квадратов);
инкапсуляцию данных (координаты фигур скрыты от прямого доступа);
вычисление площади отдельных фигур;
суммирование площадей всех объектов в общем списке.
2. Архитектура проекта
Программа построена на трёх фундаментальных принципах объектно-ориентированного программирования:
2.1 Инкапсуляция (защита внутреннего состояния)
В родительском классе Figure координаты _x и _y объявлены защищёнными (с префиксом _), что предотвращает их прямое изменение извне. Для взаимодействия с ними предусмотрены публичные методы-аксессоры:
get_coords() — возвращает текущие координаты;
set_coords(x, y) — обновляет координаты с контролем доступа.
2.2 Наследование (повторное использование кода)
Иерархия классов выстроена следующим образом:
Базовый класс Figure определяет общую для всех фигур характеристику — координаты расположения.
Производные классы Circle и Square наследуют эту функциональность и расширяют её собственными атрибутами: радиусом и длиной стороны соответственно.
2.3 Полиморфизм (единый интерфейс — множественная реализация)
Все дочерние классы реализуют метод calculate_area(), но каждая фигура вычисляет площадь по своей уникальной формуле. Благодаря полиморфизму мы можем единообразно обрабатывать разнотипные объекты в одном цикле, вызывая calculate_area() без привязки к конкретному типу фигуры.
3.Пример использования
- Создаем фигуры
circle = Circle(0, 0, 5)
square = Square(3, 4, 4)
- Получаем координаты
print(circle.get_coords())  # (0, 0)
- Изменяем координаты
circle.set_coords(10, 10)
print(circle.get_coords())  # (10, 10)
- Считаем площадь
print(circle.calculate_area())  # 78.5
print(square.calculate_area())  # 16
- Список фигур
figures = [
    Circle(0, 0, 5),
    Square(3, 4, 4),
    Circle(-2, 3, 3),
    Square(-5, -2, 6),
    Circle(10, 10, 2)
]
- Общая площадь
total = sum(fig.calculate_area() for fig in figures)
print(f"Общая площадь: {total}")  # 171.32
